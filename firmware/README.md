
# Arduino Firmware

This folder contains the Arduino source code for the obstacle-avoiding robot.

## Source Code

- `obstacle-avoidance.ino` — main Arduino program.

## Functionality

The program is designed to read distance measurements from the ultrasonic sensor and control the robot's motors through the motor driver.

## Requirements

- Arduino IDE
- Compatible Arduino board
- Required hardware connections and libraries, if applicable

## Usage

1. Download `obstacle-avoidance.ino`.
2. Open it in Arduino IDE.
3. Verify the board selection and pin assignments.
4. Compile the program and upload it to the controller.

Check the actual circuit and source code before operating the robot.
